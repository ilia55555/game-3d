# Stickman modular game

1. این پوشه نسخهٔ ماژولار و قابل‌بازی پروژه است؛ مدل، انیمیشن، کنترلر، دشمن، افکت، HUD و مرحله از هم جدا هستند.
2. کاراکتر اصلی با بدنهٔ یکپارچه‌تر، متریال تیره و دو حالت افکت یخی و آتشی ساخته شده است.
3. گیم‌پلی شامل حرکت سوم‌شخص، دویدن، پرش، شلیک انرژی، ضربهٔ نزدیک، موج دشمن و امتیاز است.
4. تمام فایل‌های کد با یک هدر ۵ خطی شروع می‌شوند تا وظیفه و مرز هر فایل سریع مشخص باشد.
5. GitHub Pages می‌تواند همین پوشه را مستقیم اجرا کند و تغییرات شاخهٔ `Ilia` بعد از Deploy قابل تست هستند.

## کنترل‌ها

```text
WASD       حرکت
SHIFT      دویدن
SPACE      پرش
Mouse      کنترل دوربین
LMB        شلیک انرژی
F          ضربه نزدیک
Q          تغییر حالت Ice / Fire
ESC        آزاد کردن ماوس / Pause
```

## وضعیت فعلی

- محیط قرمز قبلی حذف شده و صحنهٔ روشن بیرونی با چمن، سنگ، خرابه، درخت، آب، کریستال و کوه ساخته شده است.
- مدل اصلی دیگر از پوستهٔ نارنجی دور هر عضو استفاده نمی‌کند و با Capsule/Sphereهای هم‌پوشان به‌صورت یکپارچه‌تر دیده می‌شود.
- حالت `Ice` هالهٔ آبی، حرکت ذرات و شلیک یخی دارد؛ حالت `Fire` هالهٔ نارنجی، ذرات صعودی و شلیک قوی‌تر دارد.
- دشمن‌ها موجی Spawn می‌شوند، بازیکن را تعقیب می‌کنند و در فاصله نزدیک حمله می‌کنند.
- شلیک‌ها کاملاً سه‌بعدی و قابل مشاهده‌اند و برخورد یخی دشمن را کند و برخورد آتشی آن را برای مدتی می‌سوزاند.

## قانون توسعه

`main.js` فقط سیستم‌ها را به هم متصل می‌کند. منطق جدید باید داخل پوشهٔ مربوط به خودش اضافه شود تا تغییر مدل، افکت، AI، HUD یا مرحله روی بخش‌های دیگر اثر ناخواسته نگذارد.
