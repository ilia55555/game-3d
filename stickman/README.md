# Stickman modular project

1. این پوشه نسخهٔ جدید و ماژولار بازی است و فعلاً تمرکز آن فقط روی طراحی و تأیید مدل استیک‌من است.
2. مدل، متریال، انیمیشن، گیم‌پلی، دشمن، سیستم دمیج و طراحی مرحله هرکدام فایل و پوشهٔ جدا دارند.
3. فایل‌های gameplay/enemies/combat عمداً در این فاز غیرفعال‌اند تا ظاهر و ریگ کاراکتر بدون تداخل منطق بازی اصلاح شود.
4. تمام فایل‌های کد با یک هدر ۵ خطی شروع می‌شوند تا وظیفه و مرز هر فایل در همان ابتدای فایل مشخص باشد.
5. بعد از تأیید مدل، همین ساختار بدون تبدیل دوباره به فایل غول‌پیکر برای تیراندازی، قطع عضو، AI و مراحل توسعه داده می‌شود.

## اجرا

این پروژه از ES Module استفاده می‌کند، بنابراین بهتر است از داخل پوشهٔ `stickman` با یک وب‌سرور محلی اجرا شود:

```bash
python -m http.server 8080
```

سپس باز کن:

```text
http://localhost:8080
```

## وضعیت فعلی

- مدل سه‌بعدی کاملاً procedural است و از فایل مدل خارجی استفاده نمی‌کند.
- ظاهر فعلی: هستهٔ مشکی، هاله/لبهٔ نارنجی، سر گرد و چشم‌های سفید تهاجمی نزدیک به مرجع تصویری.
- سر، دست‌ها و پاها گروه‌های مستقل دارند و برای سیستم قطع عضو آینده آماده‌اند.
- Idle، Walk و Combat Pose فقط برای بررسی ریگ فعال شده‌اند.
- دکمه‌های اعضا در پنل برای مخفی/نمایان کردن مستقل قطعات و تست مرزبندی مدل هستند.

## قانون توسعه

هیچ سیستم بزرگی داخل `main.js` نوشته نشود. `main.js` فقط سیستم‌ها را به هم متصل می‌کند. هر قابلیت جدید باید در پوشهٔ مربوط به خودش پیاده‌سازی شود تا تغییر مدل، انیمیشن، AI یا مرحله روی بقیهٔ بخش‌ها اثر ناخواسته نگذارد.
